# Writing Viral Tweets

This skill enables the agent to craft high-conversion tweets for X.com by combining deep research with psychological triggers and modern social media copywriting techniques.

## When to use this skill
- When the user asks to "write a tweet" or "create content for X".
- When a topic needs promotion or viral reach.
- When the user provides a raw idea that needs to be "hook-ified".

## Workflow
1.  **Requirement Gathering**:
    - [ ] Ask the user for the **topic** or direct input.
    - [ ] Identify the **target audience** if not obvious.
2.  **Deep Research**:
    - [ ] Use `search_web` to find:
        - Recent news/trends related to the topic.
        - Emotional pain points or desires of the audience.
        - Counter-intuitive facts or surprising data.
3.  **Content Drafting**:
    - [ ] Generate **3 distinct tweet variations** using the guidelines below.
    - [ ] Include a clear **Call to Action (CTA)** in each.
4.  **Refinement**:
    - [ ] Ensure the final tweet is under 280 characters.
    - [ ] Verify clickbait "Value-to-Hook" ratio (delivers on the promise).

## Guidelines for Viral Tweets
- **The Hook**: Start with a "scroll-stopper" (e.g., "Most people think X, but the truth is Y", "I spent 100 hours researching X so you don't have to").
- **Conciseness**: Avoid fluff. Every word must earn its place.
- **Visual Spacing**: Use line breaks to make it readable.
- **CTAs**: Be specific (e.g., "RT if you agree", "Check the link below", "Reply with your thoughts").
- **Clickbait Density**: Use emotional triggers (Curiosity, Urgency, Scarcity).

## Research Prompt Template
When researching, use queries like:
- `latest trends in [topic] twitter 2024`
- `controversial opinions about [topic]`
- `surprising statistics for [topic] 2024`
